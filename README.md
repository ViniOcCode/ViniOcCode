# Vinicius Octavio Pereira Cavalheiro

**Software Developer | Backend, REST APIs and SQL | Python**

Software developer and Computer Science student focused on backend development, REST APIs, integrations, databases, automated tests, and containers.

I use AI as an engineering tool with controlled workflows: reusable agent skills, task-specific harnesses, guardrails, structured prompts and context, automated tests, security checks, and human review. This keeps AI-assisted work reproducible and verifiable instead of treating generated output as automatically correct.

In a paid confidential freelance project, I independently built a web dashboard that automated the full Mercado Livre listing creation and publishing workflow. The system included an editor for updating published listings and a general audit workflow through the Mercado Livre API. I integrated OAuth2, cloud storage, Seller7, Google Drive, and AI-assisted image and listing creation. The automation processed more than 500 listings.

In another freelance project, I built a Python desktop application to manage DigitalOcean instances, validate IP addresses and DNS, run remote SSH configuration, and automate an email advertising workflow with IMAP reading and HTML templates. The application was distributed for Windows with PyInstaller.

I am open to internship and junior software development and backend opportunities in Brazil.
